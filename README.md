# IDRS Diabetes Risk Calculator

## About
A Python-based implementation of the Indian Diabetes Risk Score (IDRS)
for estimating diabetes risk based on selected demographic and lifestyle
factors.

## Features
- Age-based scoring
- Waist circumference scoring
- Family history scoring
- Physical activity scoring
- Input validation
- Automatic IDRS calculation
- Risk classification

## Technologies
- Python

## How to Run
python idrs_calculator.py

## Risk Categories
0–30   → Low Risk
31–59  → Moderate Risk
60–100 → High Risk

## Limitations
This tool is an educational implementation of the IDRS and is not intended
to diagnose diabetes or replace professional medical assessment.
